# Управление Veprais Launcher

Этот репозиторий должен быть публичным. Лаунчер читает файл `config.json` из ветки `main` при каждом запуске.

- `servers` — сервер VEPRAIS: измените `host`, `port`, лимит игроков и изображения.
- `news` — новости главной страницы. Для новой новости добавьте объект с уникальными `id` и `alias`.
- `media` — карточки стримеров и видео.
- `links` — кнопки сайта и социальных сетей.
- изображения положите в папку `assets` и укажите их raw-ссылки в `config.json`.

## Выпуск обновления лаунчера

1. Соберите новую версию установщика.
2. На странице GitHub откройте **Releases → Draft a new release**.
3. Создайте тег версии, например `v1.0.0.8`.
4. Прикрепите один установщик `.exe` и опубликуйте Release.

Лаунчер сам прочитает последний Release. Название релиза и его описание будут показаны пользователю как сведения об обновлении.
